# Offline synthetic demonstration

This is a software check on an artificial 400 by 500 pixel scene with known generated water classes. It is not Lagos data, a satellite observation or evidence of real-world accuracy.

| Period | Agreement with generated truth | Valid pixels |
|---|---:|---:|
| Dry | 99.868% | 200,000 |
| Wet | 99.850% | 197,500 |

The fake world contains a winding river, lake, seasonal pond, shadow, reclaimed patch, coarse historical labels and a wet-season cloud gap. The demo run created maps, presentation images, model rules, metrics and logs under `outputs/demo/`. `known_truth_checks.json` is generated by comparing the pipeline's maps with the planted class mask.
